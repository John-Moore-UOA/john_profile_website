## Overview

A broad introduction to computer systems engineering, from logic gates up to C programs running on a microcontroller. I designed small digital systems on an FPGA and programmed an ATmega328P in the labs.

## Topics covered

### Digital logic

- Boolean algebra and logic gates
- Combinational circuit design
- Sequential logic and flip-flops
- Finite state machines

### FPGA design

- Implementing digital designs on an FPGA
- Hardware description and simulation
- Testing designs in the lab

### Microcontrollers and low-level software

- ATmega328P architecture
- Embedded C programming
- I/O, timers and interrupts
- Linking software to the physical world

## Skills and tools

Digital logic, Boolean algebra, finite state machines, FPGA, Verilog, embedded C, ATmega328P, microcontrollers, hardware debugging
