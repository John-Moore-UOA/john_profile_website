## Overview

A course in two halves: designing and using database applications, then looking inside a database management system to see how it actually works.

## Topics covered

### Database design and use

- Relational model and schema design
- SQL querying
- Normalisation
- Building database applications

### Inside a DBMS

- Storage and indexing
- Query processing and optimisation
- Transactions and concurrency control
- Recovery

## Skills and tools

SQL, relational databases, database design, normalisation, indexing, query optimisation, transactions, data modelling
