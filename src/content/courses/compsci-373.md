## Overview

An introduction to how images are processed and how 3D scenes are modelled and rendered. It balances the maths behind graphics with hands-on coding, so I wrote code for both image filtering and rendering techniques.

## Topics covered

### Graphics fundamentals

- Graphics primitives and rasterisation
- Lighting and shading models
- Texture mapping
- Ray tracing

### Geometry and transformations

- Geometric transformations with matrices
- Viewing and projection matrices
- Curve and surface representation
- Digital geometry

### Image processing

- Image representation, perception and colour models
- Grey-level and colour enhancement
- Neighbourhood operations and filtering
- Image segmentation

## Skills and tools

Computer graphics, image processing, linear algebra, 3D transformations, ray tracing, shading, image filtering, segmentation, programming
