## Overview

The advanced software design course, building on SOFTENG 206 with a larger team project for realistic clients. There was more independence expected, and the projects involved modern technologies including agentic AI.

## Topics covered

### Team project delivery

- Alpha, beta and final deliverables
- Technical decision-making and ownership
- Evaluating the software built

### Client engagement

- Requirements gathering
- Design meetings and demos
- Presenting to clients

### Independent learning

- Picking up unfamiliar technologies
- Agentic AI in software projects
- Solving problems with limited guidance

## Skills and tools

Software engineering, team collaboration, agentic AI, client communication, technical design, Git, product demonstrations, independent learning

## Assessment

- Individual alpha code and demo
- Group beta code and demo
- Group final code and demo
