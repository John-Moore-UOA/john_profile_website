## Overview

The first software engineering design course, built around one project across the semester. I started with individual work to learn the technologies, then moved to a team project with simulated client meetings.

## Topics covered

### Project delivery

- Alpha individual product and demo
- Beta and final team products
- Iterative development toward demos

### Client and requirements work

- Simulated client design meetings
- Requirements gathering
- Communicating progress to a client

### Professional practice

- Version control with Git
- Software licences and ethical code reuse
- Working effectively in a team
- Evaluating software quality

## Skills and tools

Software design, Git, team collaboration, requirements gathering, application development, product demos, software licensing

## Assessment

- Individual alpha code and demo
- Group beta code and demo
- Group final code and demo
