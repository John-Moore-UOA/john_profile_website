## Overview

A course on software quality from two angles: building the right software through requirements, and building it right through code quality and testing.

## Topics covered

### Requirements

- Elicitation and analysis
- Specification and validation
- Requirements management and verification

### Code quality

- Code conventions and readability
- Software metrics

### Testing

- Black-box and white-box testing
- Test adequacy metrics
- Unit, integration and system testing

## Skills and tools

Software testing, requirements engineering, unit testing, code quality, software metrics, quality assurance, test design

## Assessment

- Group elicitation assignment
- Individual assignments
- Labs
- Readings and reflections
- Quizzes
