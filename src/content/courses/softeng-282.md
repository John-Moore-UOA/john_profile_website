## Overview

A maths-for-computing course where the thread running through everything is proof. I learned how to build rigorous arguments across logic, graphs, combinatorics and automata.

## Topics covered

### Logic and proof

- Propositional and first-order logic
- Proof techniques
- Equivalence relations and posets

### Discrete structures

- Integers and factorisation algorithms
- Functions and cardinality
- Graph theory

### Counting and computation

- Combinatorics and enumeration
- Coding theory
- Finite automata

## Skills and tools

Mathematical proof, discrete mathematics, logic, graph theory, combinatorics, automata, formal reasoning
